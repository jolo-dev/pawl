This page shows how to develop and test your CDK Stack locally to gain more confident when deploying.
The CDK Stack will be deployed against [Localstack](https://docs.localstack.cloud/overview/) (free version).

> Note: Localstack is not bug-free and you should still test to deploy to the development environment. Localstack should give you confident and it is a much faster approach to deploy it there first.
