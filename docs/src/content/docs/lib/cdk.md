[AWS Cloud Development Kit (CDK)](https://aws.amazon.com/cdk/) is an open-source software development framework designed to simplify the modeling and provisioning of cloud infrastructure resources using familiar programming languages. This framework allows developers to define their infrastructure as code, leveraging languages such as TypeScript, Python, Java, C#, and Go instead of traditional configuration formats like YAML or JSON used in AWS CloudFormation.

## Goal

Since HEMS is heavily involving AWS services, it can be hard to get started. This library aims to provide compliant coding block for your project.
This package will encapsulate reusable AWS resource constructs that comply with organizational best practices and security standards, streamlining the development process and ensuring consistency across projects.
