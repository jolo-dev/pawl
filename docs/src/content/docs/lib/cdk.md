[AWS Cloud Development Kit (CDK)](https://aws.amazon.com/cdk/) is an open-source software development framework for defining cloud infrastructure as code using TypeScript.

## Goal

When working with AWS services, it can be hard to get started correctly. `@pawl/cdk` provides compliant building blocks for your project.
This package encapsulates reusable AWS resource constructs that comply with best practices and security standards, streamlining development and ensuring consistency across projects.
