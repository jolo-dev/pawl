# Lambda Node.js 24 Migration

**Goal:** Deploy all Pawl Lambda functions on Node.js 24 and update current documentation without changing AgentCore's separate Node 22 runtime or adding dependencies.

**Approach:** Change the shared LambdaFunction runtime and esbuild target; DurableLambdaFunction and higher-level constructs inherit them. The installed CDK already synthesizes its S3 auto-delete helper on Node.js 24, so verify that with regression tests rather than adding an unnecessary runtime-override aspect. Preserve existing user documentation/design work and regenerate reference pages through the docs build.

- [x] Update runtime expectations and add coverage for helpers, reviewer pipelines, and local stacks; observe failures before implementation.
- [x] Set LambdaFunction to NODEJS_24_X / node24, preserving ARM64 and ESM. Remove outdated latest-runtime nag suppressions.
- [x] Update source TypeDoc diagrams/comments, package/root readmes, tutorial, CLI planning guidance, and current diagram audit. Explain that LocalStack's legacy runtime option does not override the pinned runtime. Leave historical verification reports and AgentCore Node 22 references intact.
- [x] Regenerate CDK/Lambda references with the existing docs toolchain.
- [x] Run focused tests/type checks, full LocalStack-enabled tests, lint, docs build, and scoped diff checks. Run commands serially to avoid the earlier overlapping-verification hangs.
