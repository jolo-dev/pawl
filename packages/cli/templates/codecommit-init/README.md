A Pawl CodeCommit project generated by `pawl init codecommit`.

## What this project does

This CDK project creates and seeds a retained AWS CodeCommit repository from the
local source directory. Initial content is uploaded as a CDK asset ZIP during
deployment — it is **not** a continuous sync. Later changes require a normal
Git push.

## Deploy

```bash
bun install
AWS_PROFILE=<profile> bunx cdk deploy --all
```

## Outputs

- **RepositoryName** — the created CodeCommit repository name
- **RepositoryCloneUrlGrc** — HTTPS (GRC) clone URL
- **BranchName** — the initial branch name (default `main`)

## Important notes

- The repository uses `RemovalPolicy.RETAIN_ON_UPDATE_OR_DELETE`; deleting the
  stack **will not** delete the repository.
- CDK initial seeding is **creation-only**; AWS ignores changes to the `Code`
  property after the repository exists.
- Source limits: 100 files, 6 MB per file, 20 MB total, 4 MB compressed ZIP.
